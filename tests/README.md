# Pruebas automatizadas

El material recibido no contiene un proyecto de pruebas. No se declara cobertura automatizada en esta versión. La compilación confirma que el código construye, pero no demuestra por sí sola el comportamiento de las ventas.

Al definir la suite, cubre cantidades vacías o negativas, stock insuficiente, producto inexistente y actualización del total de la sesión.
