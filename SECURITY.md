# Seguridad

NexCode Sales es un prototipo académico y no está preparado para un entorno de producción. El programa no implementa inicio de sesión ni autorización técnica, y utiliza datos de ejemplo cargados en memoria.

No publiques contraseñas, tokens, datos personales reales ni archivos privados en Issues o pull requests. Si encuentras un problema de seguridad, no publiques detalles de explotación: contacta en privado a una persona mantenedora del equipo. No hay un correo público de seguridad confirmado.
