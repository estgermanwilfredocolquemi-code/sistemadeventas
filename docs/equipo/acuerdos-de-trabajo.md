# Acuerdos de trabajo

Propuesta inicial para revisión y aprobación del equipo:

1. Registrar tareas y defectos en GitHub Issues.
2. Revisar cada pull request antes de integrarlo a la rama principal acordada.
3. Mantener README, requisitos y manual sincronizados con el comportamiento real.
4. No marcar como implementadas las funciones que solo estén planeadas.
5. No publicar datos personales reales, contraseñas ni tokens.
6. Confirmar responsables, fechas, revisores y licencia por acuerdo grupal.
7. Añadir evidencia de compilación o de comprobación manual en cambios de comportamiento.
